# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AXON, please report it privately.

**Do not open a public GitHub issue.** Instead, email the maintainer directly or use the GitHub Security Advisory tab:

1. Go to https://github.com/ezoushen/axon/security/advisories
2. Click **"Report a vulnerability"**
3. Fill in the details

You should receive a response within 48 hours. If you don't, follow up via the same channel.

## Scope

- SSH credential handling
- Remote command execution via deployment scripts
- Secrets and environment variable management
- File permission issues in install and setup scripts

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |
| Older   | ❌        |

We recommend always using the latest release.
